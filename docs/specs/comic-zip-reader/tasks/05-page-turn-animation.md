# 05 — 페이지 넘김 애니메이션(한 장 보기) + 켜기/끄기 설정

## Outcome

한 장 보기에서 좌/우 클릭 시 종이가 굽으며 넘어가는 애니메이션이 재생된 뒤 다음/이전
페이지가 보인다. 애니메이션 방향은 실제 이동 방향(다음/이전) 및 읽는 방향 설정(오→왼/
왼→오)과 일치한다. 재생 중에 다시 클릭해도 애니메이션 완료를 기다리지 않고 즉시
반영된다. 설정에서 애니메이션 표시 여부를 켜고 끌 수 있으며 기본값은 켜짐이다.

## Blockers

01 (기본 읽기 경험) — 전환 대상이 되는 읽기 화면과 넘김 로직이 있어야 한다. (완료됨)

- [x] 한 장 보기에서 좌/우 클릭 시 종이가 굽으며 넘어가는 애니메이션이 재생된 뒤
      다음/이전 페이지가 보인다.

  Revision 참고).
