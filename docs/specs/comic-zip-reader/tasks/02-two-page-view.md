# 02 — 두 장 보기(스프레드) 모드

## Outcome

한 장 보기와 두 장 보기를 언제든 전환할 수 있고, 두 장 보기에서는 1페이지가 표지로 단독
표시된 뒤 2-3, 4-5 순으로 짝지어 보인다. 좌/우 클릭 넘김과 방향 설정은 두 장 보기에서도
한 장 보기와 동일한 규칙으로 동작한다. 보기 모드를 전환해도 보던 페이지가 끊기지 않고
이어서 보인다.

## Blockers

01 (기본 읽기 경험) — 전환 대상이 되는 읽기 화면과 넘김/방향 로직이 있어야 한다.

## Acceptance criteria

- [x] 보기 모드 전환 컨트롤로 한 장 ↔ 두 장 보기를 즉시 전환할 수 있다.
- [x] 이후 스프레드는 2-3, 4-5 순으로 짝지어 표시된다(1페이지만 보던 중 두 장 보기로
      전환하면 표지가 단독으로 표시된다).
- [x] 두 장 보기에서도 좌/우 클릭 넘김과 방향 설정이 한 장 보기와 동일한 규칙으로 동작한다.
- [x] 보기 모드를 전환해도 보던 페이지가 포함된 스프레드/페이지로 이어서 표시된다(항상
      처음 페이지로 리셋되지 않는다).
